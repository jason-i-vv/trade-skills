# Stock Base — 大盘基本面分析框架

大盘基本面分析的核心是回答三个问题：**当前市场估值贵不贵？驱动逻辑是什么？风险在哪里？**

## 核心分析维度

### 1. 估值体系 (Valuation)

跨市场通用估值指标：

| 指标 | 说明 | 便宜区间 | 昂贵区间 |
|------|------|----------|----------|
| PE (P/E Ratio) | 市盈率，越低越便宜 | < 15x | > 25x |
| PB (P/B Ratio) | 市净率，蓝筹股参考 | < 2x | > 4x |
| PS (P/S Ratio) | 市销率，成长股参考 | < 3x | > 10x |
| EV/EBITDA | 企业价值倍数 | < 8x | > 15x |
| Dividend Yield | 股息率，越高越有价值 | > 3.5% | < 1.5% |
| CAPE (Shiller PE) | 周期调整市盈率 | < 15x | > 25x |

### 2. 宏观经济联动 (Macro Context)

- **货币政策**: 利率环境、央行资产负债表、流动性状况
- **财政政策**: 政府支出、税收政策、赤字水平
- **信用周期**: 社融规模、M2 增速、信用利差
- **通胀与盈利**: CPI/PPI 与企业盈利增速的相关性
- **汇率传导**: 本币贬值对出口型企业的影响

### 3. 资金与流动性 (Liquidity)

- 北向/南向资金净流向
- 两融余额变化
- ETF 净申购/赎回
- 新股发行节奏 (IPO 再融资规模)
- 解禁压力

### 4. 盈利与增长 (Earnings)

- 指数成分股整体 EPS 增速
- 营收增速 vs 利润增速的背离
- 盈利预警/上调比例
- 分析师一致预期调整方向

### 5. 风险溢价与情绪 (Risk Premium)

- 股债收益率比 (股票风险溢价 = E/P - 10Y国债收益率)
- VIX / 恐慌指数 所处百分位
- 融资融券杠杆率
- 认沽认购比 (Put/Call Ratio)

### 6. 技术面与基本面共振

基本面分析须与技术面互为验证：
- 价格在关键均线系统中的位置
- 成交量是否支持趋势延续
- 宏观驱动是否与价格趋势方向一致

---

## 分析框架流程

```
1. 宏观环境 → 确定牛熊背景 (货币、信用、盈利三周期)
2. 估值定位 → 当前估值在历史分位数哪个位置
3. 资金验证 → 基本面改善是否有资金跟进
4. 盈利确认 → 宏观改善是否传导至企业盈利
5. 风险扫描 → 识别尾部风险和结构性问题
6. 综合评分 → 给出多空方向和仓位建议
```

---

## 评分体系

| 评分 | 市场状态 | 操作建议 |
|------|----------|----------|
| 80-100 | 估值低 + 资金净流入 + 盈利改善 | 积极做多，重仓配置 |
| 60-79 | 估值合理 + 资金平稳 | 稳健做多，标配 |
| 40-59 | 估值分化，矛盾信号多 | 观望，结构性机会 |
| 20-39 | 估值高 + 资金外流 + 盈利下滑 | 减仓/做空 |
| 0-19 | 系统性风险，高估严重 | 清仓/对冲 |

## 子技能说明

- **m-stock-base**: 美股专用分析框架，涵盖美股特有指标、FED 政策、SEC 数据

加载本技能后，可直接加载对应子技能进行具体市场分析。

## 局限性

- 基本面分析适合中长线判断，不适合短线择时
- 估值低不代表立刻涨，估值高不代表立刻跌
- 宏观政策具有不可预测性，需留有安全边际
