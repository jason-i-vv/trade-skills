# 美股大盘基本面分析

专注于美股市场的大盘基本面分析框架，结合美股特有的资产定价逻辑和 FED 货币政策进行综合研判。

---

## 美股特有分析要素

### 1. FED 货币政策周期

美联储政策是美股定价的核心变量：

| 政策状态 | 股市表现 | 当前如何判断 |
|----------|----------|--------------|
| 宽松 (降息) | 股市大涨，成长股领涨 | FED 降息周期启动 |
| 紧缩 (加息) | 股市承压，价值股占优 | FED 快速加息 |
| 暂停 (暂停加息) | 震荡分化，主题轮动 | FED 维持利率不变 |
| 缩表 | 流动性收紧，高估值承压 | QT 进程 |

**关键利率指标**：
- Fed Funds Rate (联邦基金利率)
- 2Y 美债收益率 (市场对 FED 的定价)
- 10Y 美债收益率 (全球经济锚定)
- 美债收益率曲线 (2Y-10Y 利差，衰退预警)

### 2. 美股特有估值指标

| 指标 | 说明 | 便宜区间 | 昂贵区间 |
|------|------|----------|----------|
| S&P 500 PE (Forward) | 前瞻市盈率 | < 18x | > 22x |
| Shiller CAPE | 周期调整市盈率 | < 20x | > 30x |
| Nasdaq 100 PE | 科技股为主，高增长高估值 | < 25x | > 35x |
| S&P 500 PB |  | < 3x | > 5x |
| 标普 500 EV/EBITDA |  | < 12x | > 18x |
| Dividend Yield (S&P 500) |  | > 2.0% | < 1.5% |
| Fed Model (股债收益比) | E/P - 10Y 国债收益率 | > 0 股票相对债券便宜 | < -2% 股票极贵 |

### 3. 盈利分析框架

美股盈利是股价的长期驱动力：

```
标普 500 EPS 增速 ≈ f(营收增速, 利润率变化, 宏观经济, 美元指数)
```

- **营收增速**: 与 GDP 增速高度相关
- **利润率**: 工资增速 vs 生产率的博弈，税改效应
- **EPS 预期调整**: 分析师向下调多于向上调 → 警惕
- **美元指数 (DXY)**: 美元强势压制跨国企业盈利

**盈利质量检查**：
- Operating Income vs Net Income 差距
- 经常性 EPS vs GAAP EPS
- 股票回购 vs 资本支出的比例

### 4. 资金流向分析

| 资金类型 | 观察维度 | 信号意义 |
|----------|----------|----------|
| 美联储资产负债表 | 规模扩张/收缩速率 | 流动性最重要来源 |
| 美国本土 ETF 净流入 | 宽基 ETF 申购/赎回 | 机构配置情绪 |
| 国际资金流向 | 长期资本流动数据 | 美元资产吸引力 |
| 杠杆做多/做空比例 | Short Interest / Beta | 做空拥挤度 |
| 企业回购 | 回购规模和节奏 | EPS 支撑的重要来源 |

### 5. 通胀与盈利的博弈

FED 双重使命：**充分就业 + 物价稳定**

| 通胀环境 | 盈利影响 | FED 应对 |
|----------|----------|----------|
| 低通胀 (< 2%) | 宽松利于估值扩张 | 纵容甚至降息 |
| 温和通胀 (2-3%) | 健康，盈利稳 | 保持中性 |
| 高通胀 (3-5%) | 挤压实际消费和企业利润 | 加息缩表 |
| 恶性通胀 (> 5%) | 盈利和估值双杀 | 激进加息 |

**核心通胀指标**：
- CPI (整体 CPI 和核心 CPI)
- PCE (FED 优先目标)
- 薪资增速 (核心通胀粘性来源)
- 房租/住房通胀 (粘性最强)

### 6. 风险溢价与估值情绪

| 指标 | 含义 | 信号 |
|------|------|------|
| E/P - 10Y 国债收益率 | 股票相对债券的价值 | > 0 便宜，< -2% 极贵 |
| VIX 当前位置 | 隐含波动率所处分位 | > 30 恐慌，< 15 乐观 |
| Fear & Greed Index | CNN 综合情绪指标 | 极端恐惧/贪婪反转信号 |
| 标普 500 阴阳比 | 上涨/下跌家数比 | > 2 极贪婪，< 0.5 极恐慌 |

### 7. 盈利-估值-利率三角框架

```
股票价格 = f(盈利, 无风险利率, 风险溢价)
```

三个变量任何一个大幅变动都会重塑市场：
- **盈利上升** → 估值不变则股价涨
- **利率上升** → 未来盈利折现减少，估值压缩
- **风险偏好恶化** → 风险溢价扩大，估值压缩

**实际案例**：
- 2022 年：利率急升 → 估值压缩 → 盈利尚可但股价大跌
- 2023 年：盈利超预期 → 部分抵消利率压力 → 结构性机会
- 2024 年：AI 驱动盈利预期 → 科技股估值扩张

## 分析流程

```
1. FED 周期定位 → 当前是宽松/紧缩/暂停？
2. 利率环境评估 → 2Y/10Y 美债收益率曲线倒挂？
3. 估值定位 → CAPE / Forward PE 在历史分位数？
4. 盈利判断 → S&P 500 EPS 增速趋势？
5. 资金验证 → ETF 净流入 + 回购规模？
6. 风险扫描 → 通胀/衰退/地缘/流动性风险
7. 综合评分 → 多空方向 + 仓位建议
```

## 局限性

- 美股科技股 (Mag 7) 权重过大，指数估值会被少数个股绑架
- FED 政策具有不可预测性，加息/降息时点难以精确判断
- 华尔街一致预期往往过于乐观，需反向思考
- 选举年/地缘冲突放大短期波动
- 算法交易和高频交易增加日内波动率
